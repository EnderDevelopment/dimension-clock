# Minecraft Dimension Travel Mod

Dimension Clock is a Fabric Minecraft mod that adds a usable dimension clock item and a command for traveling between dimensions available on the server, including dimensions provided by other mods.

## Install

1. Install Minecraft 1.21.1, Java 21, Fabric Loader 0.16.0 or newer, and Fabric API.
2. Place the Dimension Clock mod jar in the Minecraft `mods` folder.
3. Start the game or server with Fabric.

## Use

1. Find the Dimension Clock in the Tools creative inventory tab, or obtain it through your usual item-granting method.
2. Use the clock to travel to the next available server dimension. Using it cycles through the server's available dimensions.
3. To choose a specific available dimension, run `/dimensionclock namespace:id`, such as `/dimensionclock minecraft:the_nether`.
4. Travel attempts to keep your current coordinates. If the position is obstructed in the destination, the mod uses that dimension's spawn position.
